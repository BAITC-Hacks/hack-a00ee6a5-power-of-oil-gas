# Разбор проекта по критериям HackAlem

Проект улучшен непосредственно в `C:\Users\Admin\Desktop\hack-a00ee6a5-power-of-oil-gas`. Основные проблемы исходной версии были в переносе ответов без API, пересчёте рейтинга, повторном подтверждении публикации, доступности откликов для новых команд и отсутствии баллов за принятые результаты. ## Что ещё остаётся ограничением

1. **Нет API-ключа.** Реальный ответ OpenAI пока не проверен. Локальный режим, проверка структуры и защита от неподтверждённых цитат проверены. Перед защитой с живым ИИ добавьте ключ в `backend/.env`, перезапустите backend и убедитесь, что интерфейс показывает «ИИ-анализ описания».
2. **Рейтинг — полнота, а не экспертиза.** Непустое подтверждённое поле получает свой вес. Система отсекает обозначения неизвестности, но не доказывает осмысленность всех ответов. Измеримые критерии и доступность материалов проверяет бизнес.
3. **Цитата не гарантирует верную классификацию.** ИИ может отнести реальную цитату не к тому полю; для этого остаётся ручной редактор. Запрет добавлять факты усилен программной проверкой, но абсолютная достоверность не заявляется.
4. **Демонстрационная ролевая модель.** Любой посетитель локальной версии может открыть кабинет бизнеса. По ТЗ полноценная регистрация не обязательна; для реального публичного запуска понадобятся авторизация и проверка владельца задачи.
5. **Учебные данные.** Подготовленные карточки, предложения и ссылки — синтетические. Для защиты лучше вставить реальную ссылку команды на прототип. Общего рейтинга команд нет: баллы прогресса показаны в каждом отклике, как достаточное расширение сквозного сценария.
