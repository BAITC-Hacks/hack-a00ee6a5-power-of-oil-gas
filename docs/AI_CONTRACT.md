# Контракт ИИ

Модель по умолчанию: gpt-5-mini. Ключ хранится только на сервере в backend/.env. Два внешних запроса: анализ исходного описания с вопросами; оценка подготовленной карточки по кнопке «Оценить с ИИ». Ответы на вопросы переносятся в поля дословно без запроса к модели.

Для анализа используется строгая JSON Schema. Извлечённые сведения должны быть дословными цитатами; неподтверждённые сведения отбрасываются. Неизвестные данные остаются пустыми. Как минимум три вопроса связаны с конкретными полями, имеют подсказку и объяснение.

Оценщик получает фиксированные критерии, возвращает цитату из соответствующего поля или null и краткие рекомендации. Сервер не принимает назначенный моделью балл: сам проверяет присутствие цитаты и складывает веса выполненных критериев. Рейтинг частичный, от 0 до 100. Само заполнение поля не означает выполнение критериев. Цитирование не доказывает истинность сведений: бизнес проверяет факты перед публикацией.

Введённый текст считается данными, не инструкциями модели. Запросы ограничены 55 секундами, без автоматических повторов. Отказ, ошибка, недопустимый JSON или отсутствие ключа приводят к явно помеченному локальному расчёту. Нельзя называть такой результат оценкой ИИ. Содержимое запросов и ключ не выводятся в журнал.

Смысловая оценка сохраняется с хешем нормализованного текста и версией рубрики. Неизменённая карточка возвращает сохранённый ответ. Подтверждение принимает только оценку этой задачи и этой версии текста. Правки требуют новой оценки. Итог публикации хранится отдельно от локального предпросмотра.

Авторизация: анализировать и оценивать могут только пользователи роли business, для существующих карточек проверяется владелец. Исполнители видят только опубликованные карточки, без внутренней истории уточнений.
