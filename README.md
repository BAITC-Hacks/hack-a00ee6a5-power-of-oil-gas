# AI SANA Challenge Hub

MVP для кейса **«Рейтинг качества бизнес-задач и открытый выбор команд»**.

## Сквозной сценарий

1. Бизнес вводит слабое описание задачи свободным текстом.
2. AI анализирует полноту и задаёт минимум 3 уточняющих вопроса.
3. Из ответов формируется редактируемая карточка задачи.
4. Человек редактирует и подтверждает карточку.
5. Backend рассчитывает прозрачный рейтинг 0–100.
6. Подтверждённая задача публикуется в общем каталоге.
7. Любая студенческая команда может открыть задачу и отправить предложение.
8. Бизнес вручную принимает или отклоняет предложение.

## Стек

- Frontend: React + Vite + обычный CSS
- Backend: FastAPI + Pydantic
- Database: SQLite
- AI: OpenAI API (через backend) + локальный fallback

## Формула рейтинга

| Показатель | Баллы |
|---|---:|
| Контекст | 10 |
| Потребность | 10 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Контакт | 5 |
| Формат взаимодействия | 5 |
| **Всего** | **100** |

Это прозрачная техническая декомпозиция рекомендованной формулы кейса: «Контекст и потребность» = 20, «Связь с бизнесом» = 10.
Баллы начисляются только после ручного подтверждения карточки.

### Уровни готовности

- 0–39 — Черновик
- 40–69 — Рабочая
- 70–89 — Готовая
- 90–100 — Приоритетная

Низкий рейтинг не скрывает задачу из каталога и не запрещает отклик.

## AI-правила

AI:
- анализирует только данные, которые сообщил пользователь;
- не добавляет новые факты;
- неизвестные поля оставляет `null`;
- генерирует минимум 3 уместных уточняющих вопроса;
- формирует только черновик карточки;
- не публикует карточку без подтверждения человека;
- не выбирает студенческую команду за бизнес.

Ответ AI валидируется через Pydantic. При недоступности API или некорректном ответе используется локальный fallback.

## Запуск backend

```bash
cd backend
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate

pip install -r requirements.txt
copy .env.example .env   # Windows cmd
# cp .env.example .env   # macOS/Linux

uvicorn app.main:app --reload --port 8000
```

Swagger: http://localhost:8000/docs

## Запуск frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend: http://localhost:5173

## Настройка OpenAI

Создайте `backend/.env`:

```env
OPENAI_API_KEY=your_new_api_key_here
OPENAI_MODEL=gpt-5-mini
USE_AI=true
```

**Никогда не помещайте API-ключ в React/Vite и не коммитьте `.env`.**

Если API временно недоступен, приложение автоматически использует fallback, чтобы demo не сорвался.

## Тестовый demo-сценарий

Слабое описание:

> Хотим использовать AI для уменьшения поломок насосного оборудования.

Ожидаемые уточнения:
- Какие данные по оборудованию доступны?
- Какой результат должна получить студенческая команда?
- По каким критериям бизнес примет результат?
- Кто будет использовать решение?
- Какие ограничения есть по срокам, технологиям или доступу?

После ответа пользователь проверяет карточку, редактирует её и вручную подтверждает. Только после этого система рассчитывает официальный рейтинг.
